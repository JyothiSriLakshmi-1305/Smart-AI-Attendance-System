# 🎓 Smart AI Attendance System

An AI-powered attendance management system that uses **face recognition** to automatically mark student attendance.  
The system is designed to be **faculty-centric**, allowing instructors to manage students, train models, and track attendance efficiently.

---

🚀 Features

- 👨‍🏫 Faculty login and dashboard
- 📷 Face capture for student registration
- 🧠 Face recognition–based attendance
- 📊 Class-wise attendance statistics
- 📁 CSV export of attendance records
- 🔁 Duplicate attendance prevention
- 💾 Automatic backup of attendance data
- 🌐 Deployed backend with live API (Render)
